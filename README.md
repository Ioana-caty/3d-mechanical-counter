# 🎰 Mechanical 7-Segment Counter

Final project for the 3D Printing / Design course — a fully functional 3D printed mechanical counter that replicates a classic 7-segment display, manually operated by a push button.

---

## 🎯 Project Description & How It Works

This project aims to build a completely mechanical 7-segment display. Cycling through the numbers from 0 to 9 will be achieved by pressing a top-mounted push button.

**The Mechanism Concept:**
The core mechanism is planned to convert linear motion (pressing the button) into rotational motion using a **ratchet mechanism**. This rotation will be transmitted to main shafts equipped with **cams**. As the shafts rotate, the cams will mechanically push or retract the individual segments inside the housing, sequentially forming the desired digits.
